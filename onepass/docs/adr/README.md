# Architecture Decision Records (ADRs)

This directory records significant technical decisions made for the OnePass project.

## Format

Each ADR file follows this template:

```
# ADR-NNN: [Short title]

**Date:** YYYY-MM-DD  
**Status:** Proposed | Accepted | Superseded | Deprecated  
**Decision owner:** [Name / role]  
**Reversibility:** High | Medium | Low  

## Context
What situation prompted this decision?

## Decision
What was decided?

## Consequences
What are the outcomes — positive, negative and risks?

## Alternatives considered
What other options were evaluated and why were they not chosen?

## Related open decisions
Any downstream decisions this ADR depends on or creates.
```
